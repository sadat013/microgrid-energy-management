# Python source

- `param.py`: physical and numerical constants.
- `run.py`: data loading, state propagation and simulation loop.
- `rule_based_controller.py`: priority-based dispatch logic.
- `optimization_controller.py`: scalar Pyomo mixed-integer dispatch model.
- `utils.py`: constraint checks, summaries and figures.

Run either controller from the repository root so the documented commands and
result paths remain consistent.
