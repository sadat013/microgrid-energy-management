# Report availability

The source project includes a seven-page team report titled *Data and
Forecasting in Microgrid - Rule-based and Optimizer-based Controller* by Bishnu
Pandey, Md Atiq Aziz and Fadel Muhammed Zikrillah.

The PDF is not published here because it contains institutional branding and
coauthor material whose redistribution status was not documented. Its methods,
equations, scenario findings and limitations are summarized in the README and
`docs/`. Add the original report only after confirming consent and applicable
institutional requirements.
