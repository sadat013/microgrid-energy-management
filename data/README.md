# Data

`raw/` contains the five semicolon-delimited scenario files used by the
simulation. Each file has 961 rows and four scenario columns (`S1`-`S4`) with
no missing values.

The data are copied byte-for-byte from the submitted assignment folder. Their
upstream provenance and redistribution terms were not supplied; see
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).
